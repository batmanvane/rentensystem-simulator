# Rentensystem-Simulator

Interaktiver, didaktischer Browser-Simulator für ein vereinfachtes Umlageverfahren mit
Aktivrente, privater Vorsorge, Erwerbsmigrationsdynamik, Agentenbasierte Koalitionsdynamik.

- Läuft komplett clientseitig (nur HTML, CSS, JavaScript, MathJax).
- Keine Backend-Abhängigkeiten.

## Online

https://batmanvane.github.io/rentensystem-simulator/ (Übersicht mit den drei Modellen)

## Verwendung

1. Dieses Repository klonen oder als ZIP herunterladen.
2. Die Dateien `rente.html` usw. je nach Interesse im Browser öffnen.

```bash
git clone https://github.com/batmanvane/rentensystem-simulator.git
cd rentensystem-simulator
# im Dateimanager doppelklicken oder:
open rente.html   # macOS
# oder:
xdg-open rente.html  # Linux
